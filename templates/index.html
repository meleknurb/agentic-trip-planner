Odyssey Engine Mappings

A custom-built data science framework that marries advanced RAG techniques with live geospatial verification systems.

Key Features

Wikivoyage RAG

Dynamically ingests local cultural texts, historical background, and specific city essays to feed the core contextualization vector pipeline.

Geospatial Sync

Directly queries nodes against the OpenStreetMap API, retrieving verified latitude and longitude metrics for every single suggested activity point.

Deterministic Outputs

Enforces a strict, structural JSON schema validation layer over Gemini 2.5 Flash to ensure zero text-based hallucinations during scheduling.

Balanced Time Blocks

The routing logic automatically partitions your custom day into fluid morning, afternoon, and evening activity sets based on target location density.

Supabase Architecture

Stores all compiled routes, itineraries, and user log metrics reliably within a relational PostgreSQL schema running on the cloud backend.

Row Level Security

Enforces strict RLS rules straight on the data tables, preventing cross-user workspace interference and safeguarding individual itinerary logs.

About Odyssey

Odyssey is built to eliminate the hours spent scrolling through chaotic, unverified travel data. By keeping our pipelines strict and our maps live, we build robust, deterministic pathways tailored to your target criteria.
